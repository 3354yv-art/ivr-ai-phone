# מערכת IVR עם AI לימות המשיח

מתקשרים לקו ומקבלים תפריט:
1. צ'אט קולי עם AI (עם זיכרון לאורך השיחה)
2. מייל: שמיעת הודעות חדשות ומענה בהקלטה. מי שעוד לא מחובר מקיש את כתובת המייל שלו בטלפון, מקבל מייל עם כפתור, ולוחץ עליו כדי לחבר את הג׳ימייל שלו (בלי סיסמאות)
3. חיפוש בגוגל: אומרים "אבטיח", שומעים תשובה, ואפשר להיכנס לאתרים שנמצאו
4. כניסה לאתר לפי שם: אומרים "ynet" או "מתמחים טופ"

בכל הקראה: 0 עצירה ותפריט, 4 אחורה, 6 קדימה.
תמלול וחיפוש עוברים דרך Gemini (חינם), לא דרך יחידות זיהוי הדיבור של ימות.

## הפעלה בשרת
    cd /opt/ivr-ai && npm install --omit=dev
    cp .env.example .env   # ולמלא
    sudo cp ivr-ai.service /etc/systemd/system/ && sudo systemctl enable --now ivr-ai
יש לפתוח את הפורט (3000 כברירת מחדל) בחומת האש של השרת וב-Security List באורקל.
בדיקה: http://כתובת:3000/health צריך להחזיר ok

## חיבור מייל אוטומטי (פעם אחת, למנהל)
1. כתובת https ציבורית לשרת, ומכניסים אותה ל-BASE_URL. הכי פשוט, עם Caddy:
       caddy reverse-proxy --from 129-159-151-3.sslip.io --to localhost:3000
   (ואז BASE_URL=https://129-159-151-3.sslip.io)
2. ב-Google Cloud: ליצור OAuth Client מסוג Web, להוסיף Redirect URI: BASE_URL/auth/google/callback,
   להפעיל Gmail API, ולהוסיף את הכתובות המורשות תחת Test users. מכניסים GOOGLE_CLIENT_ID ו-GOOGLE_CLIENT_SECRET.
3. שליחת המיילים עם הקישור: SMTP_* או MAIL_USER ו-MAIL_APP_PASSWORD (סיסמת אפליקציה של ג׳ימייל).
הערה: ההרשאות של ג׳ימייל נחשבות רגישות אצל גוגל. במצב בדיקה אפשר עד 100 משתמשים שמוסיפים ידנית. לפתיחה לכולם צריך אימות של גוגל.

## הגדרת השלוחה בימות המשיח (ext.ini)
    type=api
    api_link=http://כתובת-השרת:3000/ivr?key=המילה-הסודית
    api_url_post=yes

## בדיקה בלי טלפון
    npm test    # שיחת דמה מלאה מול מוקים
